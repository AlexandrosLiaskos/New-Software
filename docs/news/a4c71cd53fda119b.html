OpenAI Codex app adds Browser Use plugin

OpenAI ships a Browser Use plugin inside the Codex desktop app, allowing the GPT-5.5 backed agent to operate the in-app browser to click through rendered UIs, inspect console and network logs, and verify fixes locally.

Documented in the official Codex changelog. Browser Use is bundled as a Codex plugin.
