Xiaomi MiMo V2.5 Pro open-source MoE model with 1T parameters

Xiaomi released MiMo V2.5 Pro, a one-trillion-parameter mixture-of-experts model with 42 billion active parameters, hybrid attention architecture and a one-million-token context window. The model is MIT-licensed and reportedly matches Claude Opus 4.6 and Gemini 3.1 Pro on certain coding and agentic benchmarks.
