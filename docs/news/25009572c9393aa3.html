Claude Code /goal: persistent outcome-based execution

Anthropic added a /goal command to Claude Code that lets users define a completion condition and have Claude continue working autonomously across multiple turns until the goal is reached. Works in interactive, headless and remote sessions including Claude Code mobile.

Mirrors OpenAI Codex's /goal feature. Distinct from time-driven /loop and stop hooks; waits for an explicit completion condition.
