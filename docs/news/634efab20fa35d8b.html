Ollama integration lands in OpenAI Codex app

OpenAI's Codex desktop app now officially supports Ollama, allowing locally-hosted open-source models (Gemma 4, Qwen 3.6, DeepSeek v4) to power Codex's AI coding agent capabilities for free. Requires Ollama 0.24+ and is available on macOS and Windows, with Linux pending.
