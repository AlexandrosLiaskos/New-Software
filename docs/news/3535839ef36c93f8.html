Moonshot Kimi K2.6 open-source long-horizon coding model

Moonshot AI released Kimi K2.6, an open-source coding model designed for long-horizon execution that can manage 12+ hour autonomous sessions, 4,000+ tool calls per run, up to 300 parallel agents and a 256K context window. Pricing is $0.95/$4 per million input/output tokens (16 cents on cache hits), with weights on Hugging Face.
