Hermes Agent adds background computer use on macOS

NousResearch's Hermes Agent has shipped an early-preview background computer-use feature powered by KUA, allowing the agent to operate apps via mouse, keyboard and screen on macOS without taking over the user's active session. The integration works with any vision-capable model (Claude, GPT, Gemini, local VLMs); Windows and Linux support is planned.

Background computer-use is an early preview feature, macOS-only at launch, powered by KUA. Works with any vision-capable LLM.
