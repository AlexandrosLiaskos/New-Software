Moonshot Kimi K2.6: open-source coding model with agent swarms

Moonshot AI released Kimi Chat 2.6 (Kimi K2.6), an open-source 1T-parameter coding model reporting state-of-the-art results on SWE-bench, BrowserComp and advanced math and vision tasks. Features include 12+ hour coding sessions, 4,000+ tool calls, 300 parallel agent swarms, multi-language multi-file generation, and pricing roughly 94% and 95% cheaper than Opus 4.6 on input and output respectively. Runs locally via MLX on dual M3 Ultra Macs.

K2.6 builds on the Kimi K2 series; weights released under a Modified MIT license per Moonshot's repository.
