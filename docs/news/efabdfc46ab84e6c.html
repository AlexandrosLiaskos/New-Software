GPT-5.5 ('Spud') leak: Crest Pro Alpha checkpoint surfaces in ChatGPT

OpenAI A/B-tests a GPT-5.5 candidate (internal code name 'Spud') inside ChatGPT, with one checkpoint labelled 'Crest Pro Alpha' surfacing for some users. The host reports stronger reasoning, faster token output, improved SVG and three.js scene generation, and a Minecraft-clone with textures, inventory and animation in one shot.

GPT-5.5 was subsequently launched officially by OpenAI and surfaced in the Codex app as the recommended model. The 'Spud' / 'Crest Pro Alpha' codename is documented only via community reporting around the leak window.
