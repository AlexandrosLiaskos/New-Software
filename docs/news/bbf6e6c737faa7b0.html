Claude Code adds Blender, Autodesk Fusion and creative tool connectors

Anthropic added connectors that let Claude Code interact with Blender, Autodesk Fusion, Canva, Adobe and other creative tools. The Fusion connector exposes text-to-CAD style workflows, while the Blender connector enables scene debugging and batch script generation through the Blender Python API.
