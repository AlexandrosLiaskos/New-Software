Toolhouse: backend-as-a-service for AI agents

Toolhouse is a sponsored backend-as-a-service for building, deploying and running AI agents with built-in RAG, memory, code execution and integrations (Gmail, Smithery, Zapier, Pipedream). It offers a no-code studio, voice-driven builder (Verb AI), an MCP server and a `th` CLI for defining and deploying agents as APIs.
