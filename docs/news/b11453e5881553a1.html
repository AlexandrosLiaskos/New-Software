AionUi: open-source Cowork desktop app for 20+ AI CLIs

AionUi (referred to in the video as 'ION UI') is a free, local, open-source Cowork desktop application that hosts AI agents such as Hermes Agent, Claude Code, Codex, Gemini CLI and others. It auto-detects locally installed CLIs and stores all data in a local SQLite database.

Built with Electron + React; runs on macOS, Windows and Linux. Often presented as a free alternative to Claude Cowork.
