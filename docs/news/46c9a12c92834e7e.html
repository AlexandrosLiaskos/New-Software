Xiaomi open-sources MiMo v2.5 Pro trillion-parameter MoE

Xiaomi has released MiMo v2.5 Pro, a roughly 1.02-trillion-parameter Mixture-of-Experts model with 42 billion active parameters, a 1 million token context window and hybrid attention. Released under the MIT license for commercial deployment, the model targets long-horizon agentic workflows and software engineering, reporting competitive scores on SWE-bench Pro, GDP-Eval and Claw-Eval versus Claude Opus 4.6, Gemini 3.1 Pro and GPT-5.4 while using 40-60% fewer tokens. API pricing is $1 per million input tokens and $3 per million output tokens.

MIT license. ~1.02T parameters / 42B active; trained FP8 across ~27T tokens. Sustains 1000+ tool calls. Released alongside the MiMo v2.5 base model (native omni). Available via MiMo Studio, OpenRouter and Kilo Code (with $25 free credits).
