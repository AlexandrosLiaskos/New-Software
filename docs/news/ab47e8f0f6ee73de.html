Traycer launches Bart Mode for autonomous epic execution

Traycer has launched Bart Mode, an outer-loop AI orchestrator that takes an epic, breaks it into tickets and runs them as parallel agent batches, reviewing each batch against the spec and updating the plan when new information emerges. The mode is agent-agnostic and orchestrates whichever coding agent is connected (Claude Code, Cursor, Windsurf, Gemini CLI, Kilo Code). A complementary team-collaboration feature has also been rolled out.

Bart Mode (internally 'Smart YOLO') manages a feedback loop across specs, tickets, diffs and verification results. Distinct from Ralph-style retry loops. Available via the Traycer IDE extension for Cursor, VS Code and Windsurf.
