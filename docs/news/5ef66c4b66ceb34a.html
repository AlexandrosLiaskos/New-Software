TinyFish makes Web Search and Fetch APIs free for all developers

TinyFish has made its Web Search and Web Fetch APIs free for every developer and agent, with no credit card required. Search returns structured data with sub-500 ms latency; the Browser API spins up stealth Chrome sessions in under 250 ms; an Agent API handles multi-step tasks. Free-tier limits are 5 search queries per minute and 25 fetch URLs per minute.

REST API, MCP server, Python/TypeScript SDKs, CLI; integrations with OpenClaw, Hermes Agent, n8n, LangChain, CrewAI.
