Freebuff: free ad-supported AI coding agent built on Codebuff

Freebuff is a zero-config, fully free AI coding CLI built on top of the open-source Codebuff platform. It is monetised through in-terminal ads rather than subscriptions and ships with nine built-in sub-agents (file picker, code reviewer, browser use, thinker, etc.). Output runs on a custom GPU deployment that delivers up to 300 tokens per second.

Distributed via npm. Built on the Codebuff multi-agent architecture; free tier supported by ads displayed in the CLI.
