Claude Code Agent View: unified multi-session dashboard

Anthropic launched Agent View inside Claude Code as a research preview, providing a centralized dashboard to manage multiple concurrent Claude sessions. Users can inspect sessions, reply inline to unblock agents, and dispatch parallel coding tasks. Available to Pro, Max, Team, Enterprise and Claude API plans.

Announced as a research preview alongside other Claude Code updates. Activated via left-arrow from any active session or the 'claude agents' command in the CLI.
