Sentry ships Seer agent for production debugging

Sentry launched Seer, an AI agent that investigates production errors by pulling traces, spans, logs, and replays from existing Sentry data, walking upstream across services to identify root cause, and drafting fixes as pull requests. Open beta.

Seer Agent launched April 28 2026; January 2026 update added local-development and code-review debugging plus flat unlimited pricing.
