Anthropic releases Claude Opus 4.7

Anthropic has released Claude Opus 4.7, its most capable Opus model. SWE-bench Verified rises from 80.8% to 87.6% versus Opus 4.6 and SWE-bench Pro from 53.4% to 64.3%; MCP-Atlas reaches 77.3%, a leading score for multi-tool orchestration. Vision processes images at over three times higher resolution. Pricing is unchanged at $5 per million input tokens and $25 per million output tokens. Anthropic warns that prompts tuned for Opus 4.6 may need retuning because the new model interprets instructions more literally.

Released 2026-04-16. Available on Claude Pro/Max/Team/Enterprise, the API, Amazon Bedrock, Vertex AI and Microsoft Foundry. First Claude model to pass Anthropic's 'implicit-need' tests. Reasoning tiers shifted up one notch (low ~ old medium, etc.). Token usage per task is higher than Opus 4.6.
