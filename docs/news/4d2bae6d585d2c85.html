Kimi K2.6 agent modes including agent swarms for parallel execution

Kimi K2.6 ships with four specialised modes inside the Kimi chatbot: Instant for quick responses, Thinking for deep research, Agent for specialised tools such as slides, websites and stocks, and Agent Swarms which deploys multiple agents in parallel for long-horizon tasks. The Kimi CLI, OpenRouter and Kilo Code are listed as integration paths.

Mode set is described in transcript and demonstrated in walkthrough.
