ds4: compact systems-programming data structures in C (antirez)

Antonio (antirez) Sanfilippo's compact C library of efficient data structures for systems programming; targets memory and runtime efficiency in low-level applications.

The video summary mis-identifies the project: antirez/ds4 is in fact a local inference engine for DeepSeek 4 Flash (Metal and CUDA), not a generic data-structures library. Worth tracking on the strength of the author and the topic.
