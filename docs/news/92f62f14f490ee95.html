Qwen 3.6 Max Preview: Alibaba's flagship agentic coding model

Alibaba released Qwen 3.6 Max Preview, a flagship preview model built on Qwen 3.6 Plus with stronger world knowledge, instruction following and agentic coding. It targets multi-step development workflows, front-end generation, visual reasoning, and browser-based visual agent tasks with a 1M token context window. Priced at $1.30 per 1M input tokens and $7.80 per 1M output tokens.

Preview accessible via Alibaba's chatbot and API; not available through OpenRouter or Kilo at time of recording. Reported to outperform Claude 4.5 Opus and GLM 5.1 on selected benchmarks per the transcript.
