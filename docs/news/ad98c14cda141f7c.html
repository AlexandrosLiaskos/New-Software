Hermes Agent: self-improving autonomous agent from Nous Research

Hermes Agent is an open-source persistent autonomous agent from Nous Research, designed to run continuously on the user's infrastructure while building long-term memory and reusable skills. Released under the MIT license.

Multi-platform (Telegram, Discord, Slack, WhatsApp, Email, CLI), with five execution backends (local, Docker, SSH, Singularity, Modal).
